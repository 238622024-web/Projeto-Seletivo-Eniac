## 📚 Documentação Scrum

Este repositório agora inclui uma documentação completa de implementação da metodologia Scrum para o Sistema ENIAC LINK+.

### 📂 Estrutura da Documentação

Acesse a pasta [`documentacao-scrum/`](./documentacao-scrum/) para encontrar:

- 📋 **[Histórias de Usuário](./documentacao-scrum/01-historias-usuario.md)** - 13 User Stories organizadas em épicos
- 👥 **[Papéis e Responsabilidades](./documentacao-scrum/02-papeis-responsabilidades.md)** - Product Owner, Scrum Master e Development Team
- 🗓️ **[Planejamento de Sprints](./documentacao-scrum/03-planejamento-sprints.md)** - 6 sprints para 3 meses de desenvolvimento
- 💭 **[Conclusão Individual](./documentacao-scrum/04-conclusao-individual.md)** - Reflexões sobre desafios e aprendizados

### 🎯 Resumo do Projeto

**Sistema:** ENIAC LINK+ - Plataforma de Recrutamento  
**Duração:** 3 meses (6 sprints de 2 semanas)  
**Metodologia:** Scrum  
**Stack:** PHP, MySQL, HTML/CSS/JavaScript  

**Principais Funcionalidades:**
- Cadastro e gestão de candidatos
- Sistema de vagas e candidaturas
- Painel administrativo para RH
- Agendamento de entrevistas
- Dashboard com analytics

### 🚀 Como Usar

1. Leia o **[README da documentação](./documentacao-scrum/README.md)** para visão geral
2. Estude as **histórias de usuário** para entender o produto
3. Revise os **papéis e responsabilidades** para organizar a equipe
4. Siga o **planejamento de sprints** para execução do projeto
